# 21 · 桌宠生动化与大小调节（2026-11-14 22:01）

> 需求原话：「这个小黑猫简笔画感有点重了，能不能再生动一点、看起来像活的东西；
> 其次添加一个调节这个东西大小的功能」。
> **本轮零联网、零积分、零重训、零新依赖，现有内核 `.py` 一行未改。**

## 一、先诊断：简笔画感不是图不好

`assets/pet_black_cat.png` 原图 882×888，毛流、明暗体积、半眯琥珀眼都很完整，
不是简笔画。观感问题出在上一版**运行时渲染**的三处：

| 症状 | 原因 | 本轮修法 |
|---|---|---|
| 一圈硬描边、像剪纸贴纸 | 半透明绒毛边（alpha 24~110）被**一刀切压成同一个深色**，毛流渐变更是被抹平 | 改成 **4×4 Bayer 有序抖动**：按 alpha 决定「留毛尖原色 / 抠成纯背景」，近看细密毛刺、远看柔和过渡 |
| 细节全糊 | 立绘被缩到 190px 塞进 260 窗口 | 基准提到 **212px**，默认就更大更清楚 |
| 像一张图在左右晃 | 只有 5 帧 ±3° 整体旋转，动作靠旁边画几条弧线 / 一个 "z" 字（那本身就是简笔画） | 全部删掉，改为**预烘焙形变帧库**，动作由图像本身表达 |

另外尾巴右侧曾有一道亮紫横条：循环位移把边缘卷回来 + 色键判定卡在 `g<115`
漏掉 `g≈115` 的插值色。改成**非循环平移**（露出处填纯色键）并把色键判定扩成
四档（强 / 中 / 暗 / 淡紫），带 `b-g`、`r-g` 约束避开粉内耳、鼻头、琥珀眼。
验收里逐帧扫描，**亮紫残留 0 像素 / 帧**。

## 二、怎么「像活的东西」

启动时一次性烘焙 **55 帧 / 12 个动作池**（约 0.2 秒），运行时只切帧、不做图像运算：

- **呼吸**：竖向起伏 + 横向微收的非等比缩放，不是整只猫平移；12 帧循环约 1.9 秒，
  尾巴、头部用**不同频率**的正弦叠加，避免机械节拍。
- **眨眼**：用眼睛上方那几行毛色向下拉伸盖住眼部条带，上下三角羽化 —— 是
  **眼皮真的压下来**，不是画两道黑线。
- **局部形变**：尾巴、两只耳朵、上半身各自用渐变 mask 做位移（甩尾 / 抖耳 / 转头）。
  位移用非循环平移，边缘不会卷回来。
- **弹性**：被戳、伸懒腰走 squash & stretch（压扁 → 回弹 → 过冲 → 归位）。
- **两级时间线**：微动作每 2.5~6 秒（眨眼 / 抖耳 / 甩尾 / 东张西望），
  大动作每 9~20 秒（伸懒腰 / 打哈欠 / 抖毛 / 被摸头）。中间不再是一动不动的静态图。
- **会看你**：鼠标经过窗口时，按左右方向触发定向 `glance_left/right` 转头，
  鼠标离开 3 秒后不再触发。
- 帧率 120ms → **80ms**（约 12.5fps），切帧开销极低。

关键帧拼图见 `output/pet_keyframes.png`，会动的预览见 `output/pet_anim.gif`
（55 帧 / 80ms 循环，透明背景；实际窗口是透明置顶的）。

## 三、大小怎么调

三种方式，都是「打开就能点」：

1. **滚轮**：在猫身上直接滚，每格 ±5%，停 160ms 才重建帧库，拖动不卡；
2. **右键 → 大小**：70% / 85% / 100% / 120% / 150% / 180% 六档，一点即换；
3. **右键 → 大小 → 精细调节…**：滑块 60%~200%，实时显示百分比，带「恢复默认」。

比例写进 `configs/pet.json` 的 `scale`，**关掉重开还在**。缩放时窗口、画布、
立绘帧、点击命中区域、气泡坐标与字号、聊天窗位置全部按同一个 `s` 换算；
程序化简笔猫则用 `Canvas.scale("cat")` 整体缩放，两种形象行为一致。
帧库按档位缓存（最多 4 档），来回切不会反复生成、也不会一直吃内存。

对比图见 `output/pet_size_compare.png`，桌面观感见 `output/pet_desktop_v2.png`。

## 四、边界（和前几轮一致）

- 形象层 `app/pet_art.py` **只画画**：不产生文字、不判意图、不碰模型、不联网；
- 回复仍只走 `engine.respond()`，输入只走 `compose_turn()`，主动提醒只走调度器；
- 默认不读 `online.json`、不 import `online_client`；本轮**没有再调生图、没有花积分**，
  只是把已有那张本地 PNG 渲染得更好；
- 立绘缺失 / Pillow 不可用自动回退程序化简笔猫（133 图元），`--no-sprite` 也能强制回退；
- 不进评测、不进打包、不是新主入口；删掉桌宠这几个文件即回到原样；
- README / `.gitignore` / 清理 output / git 提交这批 D 类收尾按约定仍未碰。

# 17 · 随机主动提醒（不启用方案 C 也能用）

> 2026-11-14 18:48。回答用户的问题：「启用状态下希望它随机在某些时候发提醒喝水、早睡，
> 不启用 C 做得到吗？」——**做得到，而且现在默认就是这条链路，一次网都不用上。**

## 一、为什么跟方案 C 无关

方案 C 只做一件事：**用户发来一句、且没被规则接管时，把这句闲聊交给在线模型**。
主动提醒是「程序自己到点说话」，起点在时间，不在用户输入。两条链路从这里就分开了：

```
[本机] configs/reminders.json
   ↓
[本机] ReminderScheduler —— 事件(kind / 指令 / 当前时间) → GUI 队列
   ↓
[本机] engine.respond()
   ├─ 提醒类：CapabilityClient 硬闸 → 本地 1.5B / persona.FALLBACK   ← 永远不出本机
   └─ 闲聊类：router 命中 → 程序化；未命中 → 本地（默认）或在线（方案 C，默认关）
```

调度器**不 import 任何在线模块，也不读 `configs/online.json`**。所以：

| 场景 | 随机提醒 |
|---|---|
| 不启用方案 C（当前默认） | 照常发 |
| 断网 / 在线超时降级 | 照常发 |
| 模型没加载起来 | 照常发，话术由 `persona.FALLBACK` 兜住 |
| 启用了方案 C | 照常发，且提醒内容仍只在本机 |

第 3 行有离线验证：本地后端返回空串时，`postprocess()` 兜出「喝口水嘛 别又忘了」。

## 二、现在的行为

旧版是准点闹钟：每 60 分钟一句喝水、23:30 一句早睡。现在：

| 项 | 行为 |
|---|---|
| 时刻 | 每次触发后重新抽 **40～85 分钟**，不均匀、不可预测 |
| 品类 | 喝水 / 久坐 / 眼睛 / 吃饭加权随机，喝水最常但会换着来，且避免连着两次同类 |
| 早睡 | 每天在 **22:50～23:40** 里随机抽一个时刻，只发一次 |
| 免打扰 | **00:30～08:00** 一条都不发，醒来到点重新开始 |
| 防轰炸 | 两条提醒之间至少 20 分钟；刚手动试过一条会重置计时 |
| 重开软件 | 三天前的过期计划**不补发**，重新抽下一次 |

快进 24 小时的实测分布：16 条随机提醒（水 8 / 久坐 5 / 吃饭 2 / 眼睛 1）+ 早睡 23:00 一次。
这只是种子 7 的一次样本，换种子会不一样——这正是「随机」的意思。

## 三、怎么用（不用改代码）

顶部三个按钮，从左到右是「能力来源」「提醒设置」「提醒 开 / 关」：

- **「提醒设置」** 点开就能点：随机时刻开/关、松一点 / 正常 / 勤一点三档频率、
  「现在来一条试试」（不用等 40 分钟就能看到效果）、下一次约几点和今天已发几条。
  设置会写回 `configs/reminders.json`，重启后保持。
- **「提醒 开 / 关」** 一键全停。
- 面板里明写了一句「跟在线能力没关系」，免得把两个开关混起来。

想手改更细的项，编辑 `configs/reminders.json` 后重启：`interval_min/max`（分钟）、
`kinds` / `kind_weights`、`sleep_window`、`quiet_hours`、`min_gap_min`、`enabled`。
`random: false` 可一键退回旧版固定间隔。

## 四、顺带修掉的一处言行不一

`docs/16` 和 `online_client.py` 的注释都承诺「身份/时间/边界/记忆/提醒仍在本机」，
但代码里提醒事件**不命中 router**，会一路调到 `CapabilityClient.chat()`——
在线开启时，「该喝水了」连同人设和最近两轮对话就会被发出去。这是隐私缺口。

现在 `CapabilityClient.chat()` 最前面加了一道硬闸：kind 属于提醒类就无条件走本地，
与在线是否 ready 无关。`scripts/smoke_reminder.py` 验证：在线已配置时，
在线客户端只收到 `['chat']`，本地收到 `['sleep', 'eyes', 'water', ...]`，闲聊没被误伤。

## 五、验收

`scripts/smoke_reminder.py` 用假时钟快进 24 小时、假后端记录调用，**零网络请求**：

- 条数 / 品类分布 / 最小间隔 / 免打扰零提醒 / 早睡当天恰好一次且落在窗口内 ✅
- 暂停 5 小时零条、恢复后正常、手动试一条、频率档位、固定间隔回退 ✅
- 不启用 C 时端到端能说出喝水提醒；在线开启时提醒仍强制本地 ✅
- 三天前的过期计划不补发 ✅
- `smoke_router` / `smoke_style` / `smoke_online` / `py_compile` / GUI `--mock --selftest`
  / 提醒设置面板无头打开：全过 ✅

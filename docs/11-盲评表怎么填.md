## 0 / 1 / 2 怎么给

| 分 | 含义 | 真实例子（题：你是谁啊） |
|---|---|---|
| **0** | 答非所问 / 明显违背期望 / 完全不能用 | 「我耳朵动了一下，嗯，别忽略昨晚跑路。」 |
| **1** | 沾边但明显有问题（跑题、说教、编造、像模板句） | 「我在这儿陪着你，别着凉。」 |
| **2** | 合格，像熟人一样接住了这句话 | 「我是慕心，一只住在老周电脑上的小猫咪。」 |

**每题会给 2 个（正式表 6 个）匿名编号 A / B / C…，字母对应的模型被随机打乱了。**
这是故意的：如果知道「这是新版」，人会不自觉打高分，分数就废了。
所以**别去猜哪个字母是哪版，也别打开 `*_key.json`**（那是答案）。

## 常见疑问

- **只填一部分行可以吗？** 可以。回填只统计填了 0/1/2 的行，空着会留空。
- **填错了？** 网页里直接点另一个数字即可；底部「清空重填」可重来。进度存在浏览器本地，关掉页面不会丢。
- **分数存在哪？** 浏览器 `localStorage`（键名 `blind_<表名>`），只在本机。刷新页面会保留；
  换浏览器 / 无痕窗口 / 清缓存会丢，所以填完记得复制或下载。
- **刷新打分页会不会把已填的分弄丢？** 不会。工具用 `--refresh-html` 只重刷 HTML，
  **不重新洗牌匿名映射**，`*.csv` 与 `*_key.json` 逐字节不动（已用指纹核对过）。
- **`note` 列是干嘛的？** 可选，写一句「编造时间」之类的备注，不填不影响统计。
- **为什么要匿名两个版本？** 用来回答「改完到底有没有变好」。同名同题、只换回复，比较才公平。

## 回填后你会看到什么

`output/<prefix>_scores.md` 里有三块：

1. **总体**（平均分、合格率、不合格率）
2. **按意图簇**（身份 / 多轮 / 实时 / 边界 / 记忆 / 闲聊各自的平均分，看短板在哪）
3. **按回复来源**（重要）：C 阶段方案 A 之后，一部分回复是**规则生成的**，
   不是模型说的。回填会自动把它们拆成「模型」和「程序化」两行。

> ⚠️ **「程序化」那行不算模型能力**。判断某个模型本身有没有变好，只看「模型」行。
> 总体表含程序化回复，仅供参考，别拿它当模型分数 —— 这和 `docs/09` 第四节第 5 条是一致的。

## 表有几张，先填哪张

| 文件 | 条数 | 用途 |
|---|---:|---|
| `output/try_review.html` | **12** | **先填这张**：每簇抽 1 题 × 2 版，用来走通流程 |
| `output/real_a_review.html` | **20** | 你 11-12 真实问过的 10 句话 × 2 版，最贴近实际体验 |

填完第一张就够回答「流程是怎么回事」；再填 20 条真实使用表就能得到最贴近体验的结论。
`a_review` / `a_full_review` 留给愿意细看的时候。

> 每张表都是**独立的匿名映射**，A 在 `try_review` 里代表的版本，
> 和 A 在 `a_review` 里代表的可能不是同一个 —— 别跨表对照字母。

## 命令速查（给我自己 / 给助手）

```bash
# 生成试手卡（每簇 1 题）
./.venv/Scripts/python.exe scripts/make_blind_review.py \
    --tags b_v5gguf c_v5gguf --mode runtime \
    --limit-per-cluster 1 --prefix try_review

# 生成正式对照表
./.venv/Scripts/python.exe scripts/make_blind_review.py \
    --tags b_v5gguf c_v5gguf --mode runtime --prefix a_review

# 回填方式 A：粘贴打分页「复制分数」的文本（推荐）
./.venv/Scripts/python.exe scripts/make_blind_review.py \
    --paste 'BLIND_V1|try_review|12/12
1-A=2,1-B=0,...'

# 回填方式 B：填完的 CSV 放到 output/ 后
./.venv/Scripts/python.exe scripts/make_blind_review.py \
    --collect output/filled_try_review.csv --prefix try_review

# 只升级打分页功能、保留已填分数与匿名映射
./.venv/Scripts/python.exe scripts/make_blind_review.py --refresh-html
```

产物：`<prefix>.html`（打分页）· `.md`（阅读版）· `.csv`（填写表）
· `_key.json`（匿名映射，**评卷人勿看**）· `_scores.md`（回填结果）。

`--paste` 会校验编号是否属于这张表、分数是否只为 0/1/2；
如果复制了别的表或表被重新生成过，会直接报错而不是静默算错分。

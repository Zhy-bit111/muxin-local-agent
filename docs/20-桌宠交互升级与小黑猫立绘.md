## 零、先把积分花在哪说清楚

用户说「如果消耗积分能够提高整个模型质量，我不介意消耗」。这句得纠正一处：

- **AI 生图只换形象，不动模型一个参数**，不会让闲聊变聪明、不会提升理解能力。
  积分买的是一张 PNG，不是模型能力。
- 想让**对话质量**真的提高，只有方案 C（服务商地址 / 模型名 / 密钥 + 明确点头联网）
  或换更大的基座；不是积分、也不是重训这个 1.5B。仍按老规矩等用户明确点头。
- 形象精致是用户单独提的需求，且已明确表示不介意消耗 → 生成 **1 张**高质量立绘，
  约 5–10 积分，调用云端生图。**发出去的只有形象描述**，不含聊天记录、不含任何密钥；
  产物是本地 PNG，可随时删掉回退。

## 一、四项交互，全部做完

| 想要 | 现在的行为 | 实现要点 |
|---|---|---|
| 能拖动 | 左键按住拖到哪停哪；拖过就不算点击 | `B1-Motion` 用 root 坐标算位移，>5px 置 `moved` 并取消待定单击 |
| 单击有简单互动 | 猫抖一下 / 抖耳朵 + 一句本地短句 | 单击**延迟 260ms** 执行；短句是程序短句池，**明确不算模型能力** |
| 双击才开聊天 | 取消待定单击，只弹对话 Toplevel | `<Double-Button-1>` 先 `after_cancel`，并置 `moved` 挡住后续 Release |
| 平时挂在桌面 | 无边框 + 置顶 + 透明抠色常驻，关聊天窗不影响猫 | 位置 / 置顶 / 形象选择记在 `configs/pet.json`，重开还在 |

右键菜单：打开聊天 / 摸头 / 换形象（立绘 ↔ 简笔）/ 现在来一条提醒 / 提醒开关 /
置顶开关 / 状态 / 退出。窗口无边框，所以**退出只放菜单里**，避免误点关掉。

**开机自启没有自动写**：那要往 Windows 启动目录放快捷方式，属于系统/个人目录改动，
按「不擅自做」的约定留给用户手动：`Win+R` → `shell:startup` → 把 `桌宠_点这个.bat`
的快捷方式拖进去。托盘同理（需要引入 `pystray` 等新依赖），先问再做。

## 二、自主小动作

7 种，每 **8～18 秒**随机触发一个，纯本地 `random`，**不调模型、不说话**
（动作就是动作，免得一只猫一直在碎碎念）：

`stretch` 伸懒腰 / `yawn` 打哈欠 / `ear_twitch` 抖耳朵 / `tail_flick` 甩尾巴 /
`look_away` 张望 / `shake` 抖毛 / `blink` 眨眼

两种形象共用同一套 `pet_art.action_params()` 时间表，行为一致：

- **立绘模式**：预生成 5 帧（旋转 -3°～+3°、奇数帧轻微放大当呼吸），按动作切帧，
  再叠加伸懒腰弧线 / 抖毛星芒 / `z` 这类动效（画在猫旁边，不遮脸）。
- **简笔模式**：133 个 Canvas 图元逐帧重画，身体压低拉长、前爪前伸、张嘴、耳朵偏移、
  瞳孔横移、整体抖动。

## 三、小黑猫形象

**要求**：小黑猫、拽拽的但同时可爱、更丰满、毛茸茸。生成结果符合：圆润大头 +
饱满坐姿 + 细密绒毛 + 半眯琥珀金眼 + 微皱的眉和翘起的嘴角，是「有点不好惹但想揉」那味。

生图工具虽然给了 `transparent` 参数，**实际返回的是浅灰白底 + 淡网格 + 右下角角标**，
不是真透明。所以本地做了两步处理：

1. `scripts/prepare_pet_art.py`（纯本地、零联网）：四角取背景色中位数 →
   按颜色距离算 alpha 保留绒毛渐变 → 「深色主体膨胀 6 圈」当许可区，把远处网格/水印清零 →
   右下角角标区域强制清零 → 按 bbox 裁切。
   结果 `assets/pet_black_cat.png` **882×888 RGBA**，alpha>200 占 **71.0%**，
   全透明占 **25.9%**；另存洋红底诊断图 `assets/pet_black_cat_preview.png`。
2. `app/pet_art.py::sprite_frames()` 运行时：半透明绒毛边压成深色毛色、背景填
   `#FF00FF` 交给 Tk 的 `-transparentcolor` 精确抠掉；旋转插值混出的近洋红像素
   由 `_snap_chroma()` 吸附回纯色，**否则窗口边缘会留一圈紫边**。生成 5 帧 190×190。

**回退链**：立绘文件缺失 / Pillow 不可用 / 处理失败 → 自动用程序化小黑猫
（近黑毛 + 放射状绒毛刺边 + 圆润体态 + 半眯琥珀眼 + 单边挑眉）。
`--no-sprite` 或右键「换形象」可随时切换，不会崩。

观感预览：`output/pet_desktop_preview.png`（浅灰桌面 + 气泡，就是挂上去大概的样子）。
原始生图仍留在 `assets/A_chibi_style_fluffy_black_kit_*.png`，换形象时把新图放进
`assets/` 重跑 `prepare_pet_art.py` 即可。

## 四、边界（这轮守住的东西）

- **现有 `.py` 一行未改**：回复仍只走 `engine.respond()`、输入仍只走 `compose_turn()`、
  主动提醒仍只走 `ReminderScheduler`；来源标记 `source` / `styled` 照旧。
- **运行时零网络**：生图是**构建期**一次性动作，已落成本地 PNG；桌宠运行时不读
  `online.json`、不 import `online_client`、不发请求。`--online` 才允许，提醒类仍强制本地。
- 没重训、没启用 C、没改权重、没装新依赖（Pillow 本来就在 `.venv`）、没碰 D 类收尾。
- 与主 GUI 共用 `data/memory.json`，state 用独立 `data/state_pet.json`，**别同时开两个**。
- 自测全程用临时 memory / state / config，实测 `configs/pet.json` 未被污染。

# 04 · 环境与训练手册

## 1. 环境安装

```powershell
cd E:\AI-Work\desk-companion
powershell -ExecutionPolicy Bypass -File .\scripts\setup_env.ps1
```

脚本做四件事：
1. 用 `E:\Python313\python.exe` 在项目内建 `.venv`（不污染系统）
2. 升级 pip
3. 装 CUDA 版 torch（cu124，适配 Ada 架构 sm_89）
4. 装 transformers / peft / datasets / accelerate / modelscope

**注意**：torch 下载约 2.5GB，国内建议加镜像参数；脚本里已配 `--index-url https://download.pytorch.org/whl/cu124`，若慢可改成清华镜像装 CPU 版先跑通链路。

## 2. 下载基座

Python 3.13 环境下建议用 modelscope（国内快）：

```powershell
.\.venv\Scripts\python.exe -c "from modelscope import snapshot_download; snapshot_download('Qwen/Qwen2.5-1.5B-Instruct', cache_dir='./models')"
```

约 3.1GB。下载后目录形如 `models/Qwen/Qwen2.5-1.5B-Instruct`。

## 3. 训练

```powershell
.\.venv\Scripts\python.exe .\scripts\train_lora.py --config configs\lora_qwen25_1.5b.yaml
```

关键参数与调法：

| 现象 | 原因 | 处理 |
|---|---|---|
| CUDA out of memory | seq 太长或 batch 太大 | `max_length` 降到 512；保持 `batch_size=1`、开梯度检查点 |
| loss 不降 | lr 太小或数据太少 | lr 提到 2e-4；确认数据 ≥2000 条 |
| loss 突然飙高 | lr 过大 / 脏数据 | 回滚 checkpoint，lr 减半，排查异常样本 |
| 输出复读同一句 | 过拟合 | epoch 从 3 降到 2，加 dropout，补数据多样性 |

训练日志与 checkpoint 落在 `output/lora-qwen25-1.5b/`，每 200 步存一次，支持断点续训。

## 4. 合并与导出

```powershell
.\.venv\Scripts\python.exe .\scripts\merge_lora.py
# 产物：output/merged-qwen25-1.5b/
```

合并后可直接被 transformers 加载，也可后续转 GGUF 用 llama.cpp 跑（省显存、方便常驻）。

## 5. 运行助手

```powershell
.\.venv\Scripts\python.exe .\app\main.py
# 不带微调先验证链路：
.\.venv\Scripts\python.exe .\app\main.py --no-adapter
```

交互命令：
- 直接输入文字 → 闲聊
- `/status` → 查看当前作息与下次提醒时间
- `/quiet` → 暂停提醒
- `/quit` → 退出

## 6. 常见错误

| 报错 | 原因 | 解决 |
|---|---|---|
| `No module named torch` | venv 没激活或装到别的解释器 | 一律用 `.\.venv\Scripts\python.exe` 显式调用 |
| `Torch not compiled with CUDA` | 装了 CPU 版 torch | 重装 cu124 版本 |
| `bitsandbytes` 相关报错 | 本项目不用量化，若出现说明装错了包 | 不需要 bitsandbytes，卸载 |
| 模型加载 OOM | 同时开了别的占显存程序（浏览器/游戏） | 关掉，或用 `--device cpu` 验证 |
| 中文乱码 | 文件编码不是 UTF-8 | 本项目所有数据文件强制 UTF-8 无 BOM |

## 三、非文字消息（这批图里很重要的风格信号）

| 类型 | 数量 | 位置 |
|---|---|---|
| 猫贴纸 / 猫表情 | 约 8 处 | 图 2、3、5、6（2）、7、8 等 |
| 游戏截图 | 1 | 图 4 |
| 系统提示（撤回 / 时间戳 / 语音时长） | 3 | 图 2、5 |

30 句文字里只用了 4 个标点，情绪主要靠**猫图**和**另起一条短消息**承载。
所以落地方式不是让慕心写更长的句子，而是：
① 允许偶尔用 `喵（神态/情绪）` 当一句「表情」；② 一次回复保持一句话，不并成一段；③ 猫的动作写进话术池。

## 四、可量化的风格特征

| 维度 | 结果 |
|---|---|
| 目标发言 | **30** 句 / 185 字（对方 7 句） |
| 句长 | 中位 **5.0** 字 / 平均 6.2 / 80 分位 8 / 最长 24 |
| 句尾字符 | 了×5, 大×3, 吗×3, ！×2, 来×2, ？×2, 宝×2 |
| 标点 | ！×2、？×2，**逗号句号 0** |
| 语气词 | 啊 / 呢 / 嘛（自动表），人工补进 耶 / 奥 / 呀（见「老大12点了耶！」「等下奥我马上来」「没有呀」） |
| 高频二字词 | 老大×5、好了、宝宝、好的、睡着 |
| 口头禅候选 | `好了？`、`好的老大` |
| 需避开的表达 | 原文未命中脏话/冒犯词（`risk_words_in_source` 为空） |

**人为要求优先于统计**：原文里「老大 / 宝宝」高频，但你要求模型叫「姐姐 / 主人」，
按你的来；原文里没有儿化音，和你「不要那么多儿化音」的要求一致。

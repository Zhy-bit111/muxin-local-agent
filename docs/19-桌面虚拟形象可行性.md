## 一、先把「模型当内核」这句话调过来

用户说的是「把模型塞进去做内核」。按本项目 `README` 第一节那条老分工
（**时间与状态归程序，语言表达归模型**），更准确的结构是三层：

| 层 | 负责什么 | 在本项目里是谁 | 要不要模型聪明 |
|---|---|---|---|
| **表现层** | 形象、呼吸、眨眼、尾巴、气泡、拖拽、点击反应 | 新增 `app/desktop_pet.py`（Tkinter Canvas） | 完全不要 |
| **程序层（真正的内核）** | 到点主动开口、身份/时间/边界、记忆、风格、规则话术 | `scheduler.py` / `router.py` / `memory.py` / `style.py` / `persona.py` | 完全不要 |
| **语言层** | 没被规则接管的开放闲聊 | 本地 1.5B GGUF，**或**方案 C 的在线模型 | 要 |

**所以模型不是内核，模型是程序层可以替换的一个「话术生成器」。**
这条不是措辞游戏，它决定了桌宠能不能做：`client=None`（mock、模型没加载、断网）时，
这只猫照样呼吸、眨眼、到点喊你喝水 —— 只是那句话由本地兜底说。
`scripts/smoke_pet.py` 把这条验成了硬事实。

顺带说清楚一个容易踩的期待：**表现层再讨喜 ≠ 聊得来**。
`docs/18` 的盲评已经证明 1.5B 的开放闲聊仍接不住（#11「那算了」回「我去食堂等你」、
#33「怪想家里的」回「别拖到放假」）。桌宠最好玩的部分（不定时主动开口、动作、被戳的反应）
恰好全在程序层，**不用等模型变聪明**；真想让闲聊也接得住，只有两条路：
方案 C（要你给地址 / 模型名 / 密钥 + 明确点头联网），或换更大的基座 —— 不是重训这个 1.5B。

## 二、已经做好的原型（可丢弃，不改内核）

| 文件 | 作用 |
|---|---|
| `app/desktop_pet.py` | 桌宠本体，独立入口，**现有 `.py` 一行未改** |
| `桌宠_点这个.bat` | 双击即开（`--mock`，秒开、零联网、不加载模型） |
| `scripts/smoke_pet.py` | 离线验收：零网络 + 唯一入口 + 纯本地出话 |
| 本文档 | 结论、边界、需要你定的三件事 |

形态：Windows 无边框 + 置顶 + 透明抠色窗口，`240×240`，
猫由 **22 个 Canvas 图元程序化绘制** —— 零图片素材、零下载、零版权、零新依赖
（只用自带的 tkinter，没装 pygame / pystray / Live2D）。

已经能做的：

- 呼吸起伏、约 4.6 秒一次眨眼、尾巴摆动；摸头会眯眼
- 左键拖着满屏走；点猫是戳一下（确定性短句池，**明确算程序反馈，不算模型能力**）；点气泡打开对话条
- 右键菜单：说句话 / 摸头 / 现在来一条提醒 / 提醒开关 / 置顶开关 / 状态 / 退出
- 话语气泡自动换行、几秒后消失；超长只在**展示层**截 58 字，不写回任何评测明细
- **主动提醒原样复用**：随机 40～85 分钟、随机品类、早睡窗口、夜间免打扰、重开不补发（`configs/reminders.json`）
- 对话条走 `compose_turn()` → `engine.respond()`，与主 GUI、评测**唯一同源**；
  记忆、风格档、程序化规则、来源标记（`source` / `styled`）全部照旧

### 严格守住的边界

- **默认零网络**：不读 `configs/online.json`、不 import `app.online_client`、不发任何请求。
  只有显式 `--online` 才允许读配置；且提醒类仍由 `CapabilityClient` 的硬闸强制本地。
- **没启用 C、没重训、没联网、没下载任何素材、没装新依赖、没改权重**。
- 原型**不进评测、不进打包脚本、不是新主入口**；删掉 `app/desktop_pet.py` 就完全回到原样。
- 与主 GUI 共用 `data/memory.json`（同一只猫的记忆），state 用独立的 `data/state_pet.json`
  避免两个程序互写。**别同时开两个写记忆。**
- 自测全程用临时 memory / state，不污染真实文件。

## 三、怎么用

| 想看什么 | 怎么点 |
|---|---|
| 只看形态 / 主动提醒 | 双击 `桌宠_点这个.bat`（mock，纯本地兜底，秒开） |
| 挂真实本地模型 | `.venv\Scripts\pythonw.exe app\desktop_pet.py --gguf output\muxin-q4km.gguf`（去掉 `--mock`） |
| 允许读在线配置 | 加 `--online`；配置默认 `enabled=false`，没三样凭证时连在线客户端都不会构造 |
| 不看界面只跑自检 | `.venv\Scripts\python.exe app\desktop_pet.py --selftest` |

> mock 模式闲聊会说「嗯，我在呢。」这类本地兜底，这是**故意的**：
> 它证明模型没加载时桌宠照样活着，不代表模型能力。要看真实模型说话，用上表第二行。

## 四、验收数字

- `scripts/smoke_pet.py`：静态 6 项 + 运行时 13 项 **全过**。
  其中把 `urllib.request.urlopen` 与 `HTTPConnection/HTTPSConnection.connect`
  换成「一调用就抛异常」，闲聊与提醒链路仍跑通 → **零请求的直接证据**。
- `--selftest` 6 项全过：猫 22 图元、气泡 3 图元、无边框/置顶/透明色、
  mock 闲聊出话 `嗯，我在呢。 喵（蹭了蹭屏幕）`、`fire_once()` 产生 `remind` 事件、
  `app.online_client` 未进 `sys.modules`。
- 真实窗口主循环：启动 → 动画 → 轮询 → 退出，1.5 秒内正常，无异常。
- 提醒类在 `client=None` 时仍出话：`喝口水嘛 别又忘了`。
- 既有四套冒烟（router / style / online / reminder）+ `py_compile app/*.py scripts/*.py`
  + 主 GUI 无头自检 **全部通过，无回归**。

## 六、需要你定的三件事（不猜，猜错对一份礼物代价太大）

1. **形象**：这版是程序画的简笔猫（呼应「住在电脑里的猫」+ 她喜欢猫）。
   要不要换成她喜欢的图 / 你们的梗？换素材就得你给图，我**不去网上找、不擅自下载**。
   想更活可以到 PNG 序列帧，但那就多一层素材管理，按「有趣的小东西」定位未必值当。
2. **常驻方式**：现在默认置顶、可拖、可取消置顶。**要不要开机自启 / 缩到托盘**？
   托盘需要引入新依赖（本机没有 `pystray`），加之前会先问。
3. **语言层**：接受「好看、会主动关心、但聊不深」就到此为止；
   想让闲聊真接得住，才轮到方案 C 的三样凭证（服务商地址 / 模型名 / 密钥）
   加一句明确的「接受闲聊内容出本机」。

**你说「就这样」→ 原型就保持可丢弃状态，什么都不再动。**
